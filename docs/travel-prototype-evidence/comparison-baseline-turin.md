# 对照评测：都灵走廊基线

对应实施计划 7.1 和阶段 ① 第一周第 2 项。本产品一列已经实测；ChatGPT 和小红书 AI 两列需要创始人用自己的账号运行，再按同一标准打分。创始人参与了开发，打分有偏差，结果中要注明。

## 固定输入

- 出发与返回：Bellinzona；目的地：Torino, Italy
- 日期：2026-11-13 至 2026-11-15（周五到周日，三天含往返）；2 人；公共交通
- 偏好：美食为主，节奏适中（每天约 4 处）
- 素材：以下 3 篇帖子，正文和图片原样提供

## 给 ChatGPT 的提示词

新开一个对话，先粘贴 3 篇帖子的正文；ChatGPT 能看图的话，再上传各帖图片。然后发送：

> 我们两个人 11 月 13 日（周五）从瑞士 Bellinzona 坐公共交通去意大利都灵，15 日（周日）回 Bellinzona。我们主要想吃好吃的，每天安排 4 个左右的地方，不要太赶。请根据上面这三篇小红书帖子，帮我们排一个三天的行程：每天去哪些店、按什么顺序、店与店之间怎么走，以及往返 Bellinzona 和都灵坐哪班车、几点出发几点到。每家店请写出名称和地址。

## 给小红书 AI 的提示词

在小红书搜索框打开 AI 问答，发送同一段提示词。小红书 AI 无法指定这 3 篇帖子，记下它实际引用了哪些笔记。

## 评分标准

| 指标 | 怎么量 |
| --- | --- |
| 事实错误数 | 错误的店名、地址、营业时间；编造的地点 |
| 不可行安排数 | 不存在的班次、赶不上的换乘、已经没有的末班车、同一天来回折返过远 |
| 可追溯比例 | 能找到来源（帖子原文或官方查询）的地点与交通信息占比 |
| 偏好契合度 | 1–5 分：是否以美食为主、节奏是否适中 |
| 得到可用行程的耗时 | 从开始到得到能直接出门用的行程，分钟数 |
